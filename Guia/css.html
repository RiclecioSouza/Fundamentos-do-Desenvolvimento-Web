01

PRIMEIROS PASSOS

O que é CSS?

CSS significa Cascading Style Sheets (Folhas de Estilo em Cascata). Ele descreve como elementos HTML devem ser apresentados: cores, fontes, espaçamentos e layouts. HTML dá estrutura e significado; CSS cuida da apresentação. Separar essas funções facilita manter e reaproveitar o design.

Uma regra CSS

O seletor escolhe elementos; dentro das chaves, cada declaração combina uma propriedade e um valor. O ponto e vírgula separa declarações. Uma regra pode ter várias declarações para configurar o mesmo grupo de elementos.

Onde escrever estilos?

Para este guia, usaremos uma folha externa ligada ao HTML. Ela mantém o conteúdo separado da apresentação e pode ser compartilhada por várias páginas. O atributo href deve apontar para o caminho real do arquivo CSS.

index.html · ligue a folha CSS

<head>
    <link rel="stylesheet" href="estilos.css">
</head>
<body>
    <h1 class="titulo">Minha página</h1>
    <p>Um primeiro parágrafo.</p>
</body>

estilos.css · seletor, propriedade e valor

/* Selecione o título pela classe definida no HTML. */
.titulo {
    color: #65c1ff;
    font-size: 2rem;
}

Pratique · sua primeira regra

  1. Crie index.html e estilos.css na mesma pasta.
  2. Ligue o CSS com <link rel="stylesheet" href="estilos.css">.
  3. Adicione uma classe ao título, estilize sua cor e tamanho e abra o HTML no navegador.
  4. Altere uma cor, salve e atualize. Se nada mudar, confira o nome e o caminho do arquivo.

Confira antes de seguir

  • Consigo apontar seletor, propriedade e valor numa regra?
  • A folha está ligada no <head> com o caminho correto?
02

ESCOLHER ELEMENTOS

Seletores e estados

Um seletor descreve quais elementos devem receber as declarações. Escolha seletores que expressem a intenção do estilo. Classes são úteis para reaproveitar um estilo; IDs devem identificar um elemento específico e, em CSS, tendem a tornar a prioridade mais difícil de ajustar.

Elemento, classe e ID

p seleciona todos os parágrafos; .aviso seleciona elementos com class="aviso"; #principal seleciona o elemento com id="principal". Classes podem aparecer em muitos elementos. Um ID deve ser único na página.

Relações e estados

.menu a seleciona links dentro do menu; .menu > a seleciona apenas links filhos diretos. Pseudoclasses como :hover e :focus-visible selecionam estados de interação.

Exemplo comentado

/* Todos os parágrafos. */
p {
    line-height: 1.6;
}

/* Elementos que compartilham esta classe. */
.botao {
    background-color: #14324a;
}

/* O link quando recebe foco pelo teclado. */
.botao:focus-visible {
    outline: 3px solid #65c1ff;
    outline-offset: 3px;
}

/* Links que estão dentro de uma navegação. */
nav a {
    text-decoration-thickness: 2px;
}

Pratique · estilos de cartão

  1. Crie três elementos com a classe cartao no HTML.
  2. Estilize todos com a classe e, depois, adicione uma classe cartao-destaque a apenas um.
  3. Use uma pseudoclasse de foco num link e navegue até ele usando Tab.

Erros comuns

  • Escrever cartao quando queria selecionar a classe .cartao.
  • Esquecer o ponto e vírgula entre declarações.
  • Estilizar por IDs em todos os lugares, criando regras difíceis de substituir.

Revisão rápida

Consigo prever quais elementos cada seletor alcança? O foco de teclado continua visível?

03

ENTENDER CONFLITOS

Cascata, herança e especificidade

Às vezes, duas regras tentam definir a mesma propriedade no mesmo elemento. O navegador resolve esse conflito pela cascata: considera origem, importância, especificidade e ordem das regras. Para o iniciante, prefira seletores simples e evite depender de !important.

Especificidade em termos simples

Em geral, um seletor com ID tem mais especificidade que uma classe; uma classe tem mais que um seletor de elemento. Por isso, #aviso pode vencer .aviso. Se duas regras têm a mesma prioridade, a que aparece depois costuma prevalecer.

Herança

Algumas propriedades, como cor do texto e família tipográfica, normalmente passam do elemento pai aos descendentes. Outras, como margens e bordas, não são herdadas. Se um estilo não aparece onde espera, verifique a regra vencedora nas ferramentas do navegador.

Uma regra posterior de mesma especificidade vence

.aviso {
    color: #ffb184;
}

/* Mesmo seletor: esta declaração vem depois. */
.aviso {
    color: #65c1ff;
}

Pratique · investigue um conflito

  1. Defina uma cor para todos os parágrafos e outra para uma classe aplicada a um parágrafo.
  2. Inspecione esse parágrafo nas ferramentas do navegador e veja quais declarações estão ativas ou riscadas.
  3. Troque a ordem das regras e observe o resultado. Depois experimente um seletor com ID e compare.

Erros comuns

  • Adicionar !important sempre que algo não funciona. Isso costuma esconder o conflito e dificultar futuras alterações.
  • Supor que toda propriedade é herdada do pai.
  • Acumular seletores longos para vencer a cascata, quando uma classe clara resolveria melhor.

Revisão rápida

Se um estilo não aparece, consigo investigar a regra vencedora em vez de acrescentar outra regra às cegas?

04

MEDIR E ESPAÇAR

Modelo de caixa e unidades

Cada elemento é apresentado como uma caixa. Seu conteúdo pode ser cercado por preenchimento interno (padding), borda (border) e espaço externo (margin). Entender essas camadas ajuda a controlar tamanho e distância sem recorrer a quebras de linha artificiais.

O que inclui a largura?

Com o padrão content-box, width define só a área de conteúdo; preenchimento e borda aumentam o tamanho total. Com border-box, esses itens entram na largura definida, o que torna o dimensionamento mais previsível.

Unidades úteis

px é uma unidade CSS fixa; % depende do contexto; rem se relaciona ao tamanho de fonte raiz; em depende do contexto tipográfico. vw e vh se relacionam à janela de visualização, mas não são necessários para todo tamanho.

Configuração inicial e cartão

/* Tamanhos mais previsíveis em todos os elementos. */
*, *::before, *::after {
    box-sizing: border-box;
}

.cartao {
    width: min(100%, 32rem);
    padding: 1.25rem;
    border: 1px solid #28303a;
    margin-block: 1rem;
}

Pratique · ajuste um cartão

  1. Crie uma caixa com largura, preenchimento e borda.
  2. Compare content-box e border-box usando as ferramentas do navegador.
  3. Use rem para texto e espaçamento. Aumente o zoom do navegador e veja se o conteúdo continua confortável.

Erros comuns

  • Usar margin quando o espaço necessário é dentro da borda (ou vice-versa).
  • Fixar largura em pixels para todo dispositivo, causando conteúdo cortado em telas estreitas.
  • Usar 100vw sem necessidade; pode incluir a largura da barra de rolagem e causar rolagem horizontal.

Revisão rápida

05

ARRANJAR ELEMENTOS

Flexbox e Grid

Layouts modernos organizam itens sem precisar posicionar cada elemento manualmente. Flexbox funciona bem para alinhar itens numa dimensão principal; Grid organiza linhas e colunas. Ambos podem se adaptar ao espaço disponível.

Flexbox para uma direção

Defina display: flex no contêiner. gap cria espaço entre itens; justify-content distribui pelo eixo principal; align-items alinha pelo eixo transversal. A direção pode ser linha ou coluna.

Grid para linhas e colunas

Defina display: grid no contêiner. grid-template-columns define colunas e gap o espaço entre células. Combinações como repeat(auto-fit, minmax(...)) permitem ajustar quantas colunas cabem.

Exemplos comentados

/* Alinha itens em uma linha e deixa espaço entre eles. */
.barra {
    display: flex;
    align-items: center;
    justify-content: space-between;
    gap: 1rem;
}

/* Cartões criam colunas conforme o espaço disponível. */
.grade {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(min(100%, 14rem), 1fr));
    gap: 1rem;
}

Pratique · galeria de cartões

  1. Monte três cartões em HTML, cada um com título e descrição.
  2. Organize-os em Grid com colunas flexíveis e um gap.
  3. Use Flexbox para alinhar uma barra com nome do site e links de navegação.
  4. Redimensione a janela e observe como o layout responde.

Erros comuns

  • Usar position: absolute para montar todo o layout. Ele remove elementos do fluxo normal e exige coordenadas explícitas.
  • Esquecer de aplicar display: flex ou display: grid ao contêiner.
  • Definir colunas rígidas que não cabem no espaço estreito.

Revisão rápida

O problema é alinhar itens numa direção ou estruturar linhas e colunas? Escolhi Flexbox ou Grid de acordo?

06

CRIAR UMA LINGUAGEM VISUAL

Tipografia, cores e variáveis

Regras visuais consistentes ajudam as pessoas a perceber hierarquia e a ler o conteúdo. Escolha fontes legíveis, contraste suficiente e espaçamentos coerentes. Variáveis CSS permitem reutilizar valores e mudar uma paleta sem editar cada regra individualmente.

Texto legível

font-family escolhe a família; font-size define o tamanho; line-height controla a altura da linha; font-weight define o peso. Priorize leitura confortável em diferentes tamanhos de tela.

Variáveis e escala flexível

Uma propriedade personalizada começa com -- e pode ser usada com var(). clamp(mínimo, preferido, máximo) permite que um valor aumente com limites, por exemplo para um título fluido.

Exemplo comentado

:root {
    --cor-texto: #f1f4f8;
    --cor-destaque: #65c1ff;
    --espaco: 1rem;
}

body {
    color: var(--cor-texto);
    font-family: system-ui, sans-serif;
    line-height: 1.65;
}

h1 {
    color: var(--cor-destaque);
    font-size: clamp(2rem, 6vw, 4rem);
    margin-block-end: var(--espaco);
}

Pratique · crie seus tokens

  1. Defina variáveis para cor do texto, cor de destaque e espaço comum em :root.
  2. Use-as em títulos e cartões.
  3. Mude uma variável e observe quantas partes do visual são atualizadas.

Revisão rápida

O texto tem contraste e espaçamento confortáveis? Valores repetidos estão representados por variáveis úteis?

07

ADAPTAR A DIFERENTES TELAS

Responsividade e movimento

Uma interface responsiva funciona em diferentes larguras, níveis de zoom e modos de entrada. Prefira começar com conteúdo fluido e ajustar o layout quando ele deixar de caber. Media queries permitem aplicar regras condicionais; respeite também a preferência do sistema por movimento reduzido.

Media queries

@media agrupa regras que valem sob uma condição. Uma condição de largura pode mudar colunas para uma única coluna quando o espaço diminui. Escolha o ponto de mudança observando o conteúdo, não um modelo específico de aparelho.

Interações e animações

transition suaviza mudança de estado; @keyframes define etapas de uma animação. Use movimento com moderação e forneça uma alternativa quando a pessoa prefere movimento reduzido.

Exemplo comentado

.grade {
    display: grid;
    grid-template-columns: repeat(3, minmax(0, 1fr));
    gap: 1rem;
}

/* Em telas mais estreitas, uma coluna evita cartões apertados. */
@media (max-width: 40rem) {
    .grade {
        grid-template-columns: 1fr;
    }
}

/* Remova transições quando a pessoa pede menos movimento. */
@media (prefers-reduced-motion: reduce) {
    *, *::before, *::after {
        scroll-behavior: auto !important;
        animation-duration: .01ms !important;
        transition-duration: .01ms !important;
    }
}

Pratique · teste tamanhos

  1. Construa uma grade de cartões e abra a página em uma janela larga e outra estreita.
  2. Observe quando os cartões ficam apertados e escolha um ponto de quebra adequado ao conteúdo.
  3. Teste zoom do navegador e navegação por teclado. Mantenha o foco visível e evite exigir hover.

Erros comuns

  • Escrever um valor CSS inválido ou esquecer a unidade, por exemplo width: 30;.
  • Esconder conteúdo em telas pequenas para fazê-lo caber, sem alternativa.
  • Usar animação contínua ou intensa sem considerar movimento reduzido.

Revisão rápida

A página continua utilizável em tela estreita e com zoom? O movimento pode ser reduzido? Controles continuam acessíveis por teclado?

08

JUNTAR AS PEÇAS

Projeto final: página de cartões

Crie uma página com cabeçalho, introdução e uma grade de cartões sobre um tema que você goste. Use HTML para a estrutura e CSS para apresentação; teste em tamanhos diferentes antes de considerar o trabalho pronto.

Requisitos

  • Uma folha CSS externa ligada corretamente.
  • Classes reutilizáveis e seletores simples.
  • Variáveis para cores e espaçamentos.
  • Grid ou Flexbox usado conforme a necessidade do layout.
  • Uma media query que preserve a leitura em tela estreita.

Checklist de revisão

  • O texto continua legível e com contraste?
  • Existe rolagem horizontal acidental?
  • O foco de teclado está visível?
  • Os estilos permanecem fáceis de encontrar e mudar?
  • O layout funciona com conteúdo maior que o exemplo?

O que você aprendeu

Você praticou regras, seletores, cascata, modelo de caixa, unidades, layouts, variáveis e media queries. CSS é iterativo: ajuste uma regra de cada vez e use as ferramentas do navegador para entender o resultado.
