01
CONCEITO

Introdução ao CSS

CSS (Cascading Style Sheets) controla a apresentação de documentos HTML: cores, fontes, espaçamentos, dimensões, posicionamento, layouts, transições e adaptação a telas diferentes.

Formas de aplicar

Inline: atributo style; interno: regras em <style>; externo: arquivo separado ligado com <link rel="stylesheet">. O arquivo externo favorece organização e reutilização.

Anatomia de uma regra

Uma regra reúne seletor e declaração: .cartao { padding: 1rem; }. O seletor escolhe elementos; a propriedade indica o que configurar e o valor define como.

Cascata e modelo de caixa

Cascata, herança e especificidade ajudam a determinar a regra aplicada. A caixa contém conteúdo, padding, borda e margin. Com box-sizing: border-box, largura e altura incluem preenchimento e borda.

Regra CSS
.cartao {
    color: #f1f4f8;
    background: #11151b;
    padding: 1.25rem;
    border: 1px solid #242a33;
    border-radius: 14px;
}
02
SELETORES

Seletores e estados

Seletores escolhem quais elementos receberão estilos. Combine-os com intenção e evite especificidade excessiva.

Seletores básicos

Elemento: p; classe: .card; ID: #principal; universal: *; atributo: input[required]. Separe seletores agrupados por vírgula: h1, h2, h3.

Combinadores

Descendente: .menu a; filho direto: .menu > a; irmão adjacente: h2 + p; irmãos gerais: h2 ~ p. Eles descrevem relações na árvore HTML.

Pseudoclasses

Estados e posições: :hover, :active, :focus, :focus-visible, :focus-within, :visited, :link, :first-child, :last-child, :nth-child(), :not(), :is(), :where(), :checked, :disabled, :enabled, :required e :root.

Pseudoelementos

::before, ::after, ::first-letter, ::first-line, ::placeholder, ::selection e ::marker estilizam partes ou criam conteúdo decorativo. Pseudoclasses usam normalmente um dois-pontos; pseudoelementos, dois.

Exemplos
.card:hover {
    border-color: #55b7ff;
}

input:focus-visible {
    outline: 2px solid #55b7ff;
}

.lista > li:first-child {
    font-weight: 700;
}

input[required] {
    border-left: 3px solid #ff9e6d;
}

.titulo::after {
    content: " *";
    color: #ff9e6d;
}
03
PROPRIEDADES

Propriedades, unidades e funções

O CSS oferece recursos para compor interfaces flexíveis. Escolha unidades e funções conforme o contexto em vez de fixar todas as dimensões em pixels.

Aparência e texto

color, background, gradientes, opacity, font-family, font-size, font-weight e text-align controlam cores, fundos e tipografia.

Espaço e posicionamento

margin, padding, border, width, height, display, position, z-index, overflow e box-sizing controlam dimensões, fluxo e camadas.

Flexbox e Grid

Flexbox organiza itens em uma dimensão, linha ou coluna. Grid organiza linhas e colunas. Ambos criam layouts adaptáveis sem depender de posicionamento absoluto para tudo.

Unidades

px é unidade CSS fixa; % depende do contexto; em depende do tamanho de fonte relevante; rem usa a fonte raiz; vw e vh são relativos à viewport.

Variáveis e funções

Defina tokens em :root e reutilize com var(). calc() calcula expressões; min()/ max() escolhem limites; clamp() combina mínimo, valor preferido e máximo; minmax() e repeat() ajudam a definir grades.

Cores e gradientes

rgb()/rgba() e hsl()/hsla() representam cores. linear-gradient() cria transição linear e radial-gradient() cria transição radial.

Variáveis e layout fluido
:root {
    --espaco: 1rem;
    --azul: #55b7ff;
}

.grade {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
    gap: var(--espaco);
}

.titulo {
    font-size: clamp(1.8rem, 5vw, 3.5rem);
    color: var(--azul);
}
04
MOVIMENTO E ADAPTAÇÃO

Transformações, transições e responsividade

Transformações alteram visualmente posição, rotação, escala ou inclinação. Transições suavizam mudanças entre estados; animações executam sequências definidas em quadros-chave.

Transformações

translate(), translateX() e translateY() deslocam; rotate() gira; scale(), scaleX() e scaleY() redimensionam; skew() inclina. transform-origin muda a origem; rotateX(), rotateY() e translateZ() permitem transformações 3D.

Transições

transition-property escolhe a propriedade; transition-duration define duração; transition-timing-function define ritmo; transition-delay define atraso. Funções: ease, linear, ease-in, ease-out, ease-in-out e cubic-bezier().

Animações

@keyframes define etapas e animation configura duração, repetição, direção e estado final. Use transições para mudanças de estado e animações para sequências próprias.

Responsividade

@media aplica regras sob condições, como largura da tela. Combine layouts fluidos com Flexbox/Grid. prefers-reduced-motion permite respeitar preferências de movimento reduzido.

Exemplo responsivo e acessível 
.botao {
    transition: transform .2s ease;
}

.botao:hover {
    transform: translateY(-2px);
}

@keyframes aparecer {
    from {
        opacity: 0;
        transform: translateY(8px);
    }

    to {
        opacity: 1;
        transform: translateY(0);
    }
}

@media (max-width: 600px) {
    .grade {
        grid-template-columns: 1fr;
    }
}

@media (prefers-reduced-motion: reduce) {
    *,
    *::before,
    *::after {
        animation-duration: .01ms !important;
        transition-duration: .01ms !important;
    }
}
Importante: ::before e ::after precisam de content. Use-os para decoração, não para informação essencial nem para substituir elementos semânticos.
