01

PRIMEIROS PASSOS

O que é JavaScript?

JavaScript é uma linguagem de programação. Um programa é uma sequência de instruções que trabalha com dados para produzir um resultado. No navegador, JavaScript pode responder a cliques, calcular valores e atualizar o conteúdo da página. HTML descreve a estrutura; CSS cuida da apresentação; JavaScript acrescenta comportamento.

Onde o código é executado?

O navegador inclui um motor JavaScript. Ele pode executar um arquivo ligado à página ou instruções digitadas no console das ferramentas do desenvolvedor. JavaScript também roda fora do navegador, por exemplo com Node.js; este guia começa pelo navegador.

Primeiro arquivo

Crie index.html e script.js na mesma pasta. O atributo defer faz o navegador executar o arquivo depois de analisar o HTML, ajudando a encontrar os elementos da página.

index.html

<!doctype html>
<html lang="pt-BR">
<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Meu primeiro programa</title>
    <script src="script.js" defer></script>
</head>
<body>
    <h1>Meu primeiro programa</h1>
</body>
</html>

script.js · abra o console do navegador para ver o resultado 

// console.log mostra um valor no console para ajudar a observar o programa.
console.log("Olá, JavaScript!");
Comentário: em JavaScript, // inicia um comentário de uma linha. Para várias linhas, use /* texto */. Comentários explicam uma decisão ou intenção; não precisam repetir o que o código já deixa óbvio.

Pratique · confirme que está funcionando

  1. Crie os dois arquivos na mesma pasta e copie os exemplos.
  2. Abra index.html no navegador e abra as ferramentas de desenvolvedor (geralmente F12).
  3. Na aba Console, encontre “Olá, JavaScript!”. Troque a mensagem, salve e atualize a página.

Confira antes de seguir

  • O arquivo script.js está ligado ao HTML por src?
  • Sei onde procurar mensagens e erros do programa?
02

GUARDAR INFORMAÇÕES

Variáveis, valores e operadores

Uma variável dá um nome a um valor para que o programa possa usá-lo. Use const quando não pretende atribuir outro valor à variável; use let quando precisar reatribuí-lo. Em código novo, normalmente não é necessário usar var, que tem regras de escopo diferentes.

Tipos que você usará primeiro

string é texto, entre aspas; number é número; boolean é true ou false. undefined costuma indicar que ainda não há valor atribuído; null representa ausência intencional. Arrays e objetos agrupam valores.

Operações e comparações

+ soma números ou junta textos; -, * e / fazem operações matemáticas. Use === para comparar igualdade sem conversão automática de tipos. = atribui um valor; não é teste de igualdade.

Exemplo comentado

const nome = "Lia";        // texto (string)
let pontos = 10;            // número (number)
const inscrita = true;      // verdadeiro/falso (boolean)

pontos = pontos + 5;        // let pode receber outro valor
const mensagem = nome + " fez " + pontos + " pontos.";

console.log(mensagem);      // Lia fez 15 pontos.
console.log(5 === "5");     // false: tipos diferentes
console.log(5 == "5");      // true: conversão implícita; evite ==

Pratique · recibo simples

  1. Crie variáveis para o nome de um produto, seu preço e a quantidade comprada.
  2. Calcule o total e mostre uma frase com console.log.
  3. Compare dois valores com === e observe o tipo de cada um com typeof.

Erros comuns

  • Esquecer aspas em texto ou usar aspas ao redor de números que serão calculados.
  • Tentar reatribuir uma variável declarada com const. O identificador é constante; um objeto guardado nele ainda pode ter propriedades alteradas.
  • Confundir = (atribuir) com === (comparar).

03

CONTROLAR O CAMINHO

Condições e repetições

Programas ficam úteis quando podem escolher o que fazer com base nos dados. Uma condição é uma expressão que resulta em verdadeiro ou falso. Um laço repete instruções; cuide para que a condição de parada seja alcançada.

Escolher com if e else

if executa um bloco quando a condição é verdadeira. else if permite testar outra condição; else cobre os casos restantes. Use chaves para delimitar os blocos e facilitar a leitura.

Repetir com for

for é útil quando você sabe quantas repetições quer fazer. while repete enquanto a condição for verdadeira. Se a condição nunca mudar para falso, o programa pode ficar preso num laço infinito.

Exemplo comentado

const nota = 6.5;

if (nota >= 7) {
    console.log("Aprovado");
} else if (nota >= 5) {
    console.log("Recuperação");
} else {
    console.log("Reprovado");
}

// Começa em 1, soma 1 a cada volta e para depois do 3.
for (let numero = 1; numero <= 3; numero += 1) {
    console.log("Tentativa " + numero);
}

Pratique · classificar números

  1. Crie uma variável com um número.
  2. Use if para informar se é positivo, negativo ou zero.
  3. Use um laço para imprimir os números de 1 até 5; depois adapte para começar e terminar em outros valores.

Erros comuns

  • Escrever if (nota = 7): isso atribui um valor. Para comparar, use === ou operadores como >=.
  • Esquecer de atualizar a variável de controle do laço.
  • Adicionar complexidade com operador ternário quando um if simples fica mais fácil de entender.

Revisão rápida

Para cada condição, consigo prever qual bloco será executado? Sei explicar quando meu laço termina?

04

REUTILIZAR LÓGICA

Funções e resultados

Uma função reúne instruções que podem ser executadas quando necessário. Ela pode receber entradas (parâmetros) e devolver um resultado com return. Dar nome às etapas ajuda a dividir um problema em partes menores e deixa a intenção do código mais clara.

Definir não é executar

Declarar uma função guarda suas instruções. Ela só roda quando é chamada pelo nome seguido de parênteses. Os nomes listados na definição são parâmetros; os valores enviados na chamada são argumentos.

Arrow functions

Uma função também pode ser escrita com =>. Para uma expressão curta, o resultado pode ser retornado implicitamente. Quando há mais de uma instrução, use chaves e escreva return.

Exemplo comentado

// preco e quantidade são parâmetros.
function calcularTotal(preco, quantidade) {
    const total = preco * quantidade;
    return total; // envia o resultado de volta a quem chamou
}

const totalCompra = calcularTotal(12, 3); // argumentos: 12 e 3
console.log(totalCompra); // 36

const dobrar = numero => numero * 2;
console.log(dobrar(4)); // 8

Pratique · conversor de temperatura

  1. Escreva uma função que receba uma temperatura em Celsius.
  2. Calcule Fahrenheit usando a fórmula C × 9 / 5 + 32 e retorne o resultado.
  3. Chame a função com alguns valores e mostre os resultados.

Erros comuns

  • Esquecer de chamar a função depois de defini-la.
  • Esperar um valor de uma função que não tem return.
  • Usar nomes genéricos como x e f quando nomes mais claros explicariam a tarefa.

Revisão rápida

05

AGRUPAR DADOS

Arrays e objetos

Arrays guardam listas ordenadas de valores; objetos agrupam dados relacionados sob nomes de propriedades. Juntos, eles ajudam a representar informação do mundo real. A posição de um array começa em zero: o primeiro item está no índice 0.

Transformar e filtrar

map() cria uma nova lista transformando cada item. filter() cria uma lista com itens que passam numa condição. find() devolve o primeiro item que corresponde. Esses métodos não alteram a lista original.

Propriedades e acesso

Use ponto para acessar uma propriedade conhecida, como pessoa.nome. Use colchetes quando o nome estiver numa variável ou tiver caracteres especiais. push() acrescenta item ao array original; tenha atenção aos métodos que modificam a lista.

Exemplo comentado

const tarefas = [
    { titulo: "Estudar", concluida: true },
    { titulo: "Praticar", concluida: false },
    { titulo: "Revisar", concluida: false }
];

const titulos = tarefas.map(tarefa => tarefa.titulo);
const pendentes = tarefas.filter(tarefa => !tarefa.concluida);
const primeira = tarefas[0];

console.log(titulos);            // lista de textos
console.log(pendentes.length);   // quantidade pendente
console.log(primeira.titulo);    // Estudar

Pratique · lista de compras

  1. Crie um array com objetos de produtos; cada objeto deve ter nome e preço.
  2. Use map() para obter só os nomes e filter() para selecionar os preços abaixo de um limite.
  3. Calcule o total. Explique em comentário se seu método muda ou preserva a lista original.

Erros comuns

  • Tentar acessar o primeiro elemento com índice 1 em vez de 0.
  • Esquecer que map() e filter() devolvem uma nova lista: guarde o resultado se quiser usá-lo depois.
  • Esperar que uma função de callback dentro de map() produza valores sem usar return ou uma expressão retornada.

06

CONECTAR AO HTML

DOM, eventos e formulários

O navegador representa o HTML como objetos numa estrutura chamada DOM (Document Object Model). JavaScript pode selecionar esses objetos e reagir a eventos, como um clique ou o envio de um formulário. Use controles HTML reais para que teclado e tecnologias assistivas também funcionem.

Selecionar e atualizar

document.querySelector() encontra o primeiro elemento que corresponde a um seletor CSS. textContent lê ou troca texto com segurança. classList permite adicionar ou alternar classes para que o CSS cuide da aparência.

Responder a eventos

addEventListener() registra uma função para ser chamada quando um evento ocorre. No envio de formulário, preventDefault() pode impedir a navegação padrão para que você apresente uma resposta na página.

index.html · elementos para o exemplo

<form id="formulario">
    <label for="nome">Seu nome</label>
    <input id="nome" name="nome" required>
    <button type="submit">Saudar</button>
</form>

<p id="saida" aria-live="polite"></p>

script.js · resposta ao envio

const formulario = document.querySelector("#formulario");
const campoNome = document.querySelector("#nome");
const saida = document.querySelector("#saida");

formulario.addEventListener("submit", evento => {
    evento.preventDefault(); // não recarrega a página neste exemplo

    const nome = campoNome.value.trim();

    if (nome === "") {
        saida.textContent = "Digite seu nome.";
        return;
    }

    saida.textContent = `Olá, ${nome}!`;
});

Por que textContent? Ele insere texto sem interpretá-lo como HTML. Evite colocar dados digitados por pessoas em innerHTML, que interpreta marcação e pode abrir brechas de segurança.

Pratique · contador de cliques

  1. Adicione um botão e um parágrafo com IDs únicos ao HTML.
  2. Selecione os dois elementos no JavaScript e comece uma variável contadora em zero.
  3. Em cada clique, incremente a contagem e atualize o parágrafo com textContent.
  4. Teste o botão com mouse e teclado.

Erros comuns

  • Usar querySelector com um seletor que não existe; o resultado será null.
  • Tentar alterar a página antes de o elemento existir. O script com defer ajuda quando o arquivo é externo.
  • Criar uma div clicável em vez de um button, que já oferece teclado e semântica apropriados.

Revisão rápida

Sei de onde vem cada elemento selecionado? A ação funciona com teclado? O texto atualizado é compreensível por leitores de tela?

07

ESPERAR OPERAÇÕES

Promises, fetch e armazenamento

Algumas tarefas levam tempo: buscar dados numa rede ou ler um arquivo, por exemplo. O JavaScript pode continuar responsivo enquanto espera. Uma Promise representa um resultado que chegará depois; async e await tornam esse fluxo mais fácil de ler.

Buscar dados com fetch

fetch() inicia uma requisição de rede e devolve uma Promise. Uma resposta HTTP de erro ainda pode ser uma resposta recebida com sucesso; confira response.ok. Use try/catch para lidar com falhas de rede ou processamento.

Guardar pequenas preferências

localStorage guarda texto no navegador entre visitas. Para salvar objetos, converta com JSON.stringify(); ao ler, use JSON.parse(). Não use armazenamento local para senhas ou outros dados sensíveis.

Exemplo: buscar e tratar uma resposta

async function carregarDados() {
    try {
        const resposta = await fetch("https://api.exemplo.com/dados");

        if (!resposta.ok) {
            throw new Error("A resposta do servidor não foi bem-sucedida.");
        }

        const dados = await resposta.json();
        console.log(dados);

    } catch (erro) {
        console.error("Não foi possível carregar os dados:", erro);
    }
}

carregarDados();

O domínio api.exemplo.com é ilustrativo e não fornece dados reais. Para testar, será preciso usar uma API disponível e respeitar suas regras de acesso.

Pratique · preferência local

  1. Salve o tema escolhido ou o nome de uma lista com localStorage.setItem().
  2. Ao abrir a página, leia o valor com getItem() e mostre-o se existir.
  3. Limpe esse valor com removeItem() e confirme o que acontece ao atualizar.

Erros comuns

  • Esquecer await e tentar usar uma Promise como se já fosse o dado final.
  • Não conferir response.ok depois de fetch.
  • Supor que dados JSON sempre existem ou têm o formato esperado; valide o que seu programa recebe.

Revisão rápida

08

JUNTAR AS PEÇAS

Projeto final: lista de tarefas

Faça uma lista pequena que permita adicionar uma tarefa e marcá-la como concluída. Comece com o HTML e o comportamento; depois, se quiser, salve a lista no navegador com localStorage.

Etapas

  1. Crie um formulário com campo rotulado e botão de envio.
  2. Guarde as tarefas em um array de objetos.
  3. Ao enviar, impeça a navegação, valide o texto e adicione uma tarefa.
  4. Escreva uma função que redesenhe a lista no DOM.
  5. Permita marcar como concluída e mostre quantas faltam.

Checklist de revisão

  • Os nomes das variáveis e funções explicam seu propósito?
  • Campos e botões podem ser usados com teclado?
  • O programa lida com campo vazio?
  • Consigo explicar de onde vêm os dados e como a página muda?
  • Testei o que ocorre quando ainda não há tarefas?

O que você aprendeu

Você praticou valores, variáveis, condições, repetições, funções, listas, objetos, eventos e atualização do DOM. JavaScript fica mais claro com pequenos experimentos: mude uma entrada, preveja a saída e confira no console.
