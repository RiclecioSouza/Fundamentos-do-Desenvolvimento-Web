01
CONCEITO

Introdução ao JavaScript

JavaScript é uma linguagem de programação usada para criar comportamento dinâmico em páginas e aplicações web. No navegador, responde a eventos, atualiza o DOM, valida formulários e consome APIs; também pode rodar no servidor com ambientes como Node.js.

HTML, CSS e JavaScript

HTML estrutura o conteúdo, CSS define a apresentação e JavaScript implementa lógica e interação.

Adicionar scripts

O JavaScript pode estar em <script> interno ou arquivo externo. Para módulos, use <script type="module" src="script.js">. O atributo defer é útil para scripts externos clássicos.

HTML
<button id="saudar">Saudar</button>
<p id="mensagem">Clique no botão.</p>
<script src="script.js" defer></script>
script.js
const botao = document.querySelector("#saudar");
const mensagem = document.querySelector("#mensagem");

botao.addEventListener("click", () => {
    mensagem.textContent = "Olá! O JavaScript respondeu.";
});
02
FUNDAMENTOS

Variáveis, tipos e operadores

Use const quando a variável não será reatribuída e let quando seu valor precisar mudar. var é legado e tem regras de escopo diferentes.

Tipos de dados

Tipos primitivos: string, number, boolean, undefined, null, bigint e symbol. Arrays e objetos agrupam dados.

Operadores e conversão

Aritméticos: +, -, *, /, %. Comparação: >, <, ===. Lógicos: &&, ||, !. Atribuição: =, +=. Prefira === a == para evitar coerções implícitas.

Variáveis
const nome = "Lia";       // string
let pontos = 10;          // number
const ativo = true;       // boolean
let resposta;             // undefined
const ausente = null;     // ausência intencional
const precos = [12, 25];  // array
const usuario = { nome, ativo };

pontos += 5;

const idade = Number("20");
03
CONTROLE DE FLUXO

Condicionais, laços e funções

Condicionais escolhem caminhos; laços repetem tarefas; funções agrupam lógica reutilizável e podem receber parâmetros e devolver resultados com return.

Condicionais

if, else if e else avaliam condições; switch compara casos; o ternário condição ? A : B serve para escolhas simples.

Laços

for controla repetições; while repete enquanto a condição é verdadeira; do...while executa ao menos uma vez. for...of percorre valores iteráveis; for...in percorre chaves enumeráveis. break encerra e continue pula uma iteração.

Funções e escopo

Use declaração de função, expressão ou arrow function. Parâmetros são nomes declarados; argumentos são valores passados. Escopos global, de função e de bloco determinam acesso às variáveis. Callbacks são funções passadas a outras; closures mantêm acesso ao escopo de criação.

Exemplo
function classificarNota(nota) {
    if (nota >= 7) return "Aprovado";
    if (nota >= 5) return "Recuperação";

    return "Reprovado";
}

const dobrar = numero => numero * 2;

for (const numero of [1, 2, 3]) {
    console.log(dobrar(numero));
}
04
COLEÇÕES

Arrays e objetos

Arrays guardam listas ordenadas; objetos agrupam propriedades. Alguns métodos alteram o array original, enquanto outros retornam novos resultados.

Métodos que modificam

push() adiciona ao fim; pop() remove do fim; shift() remove do início; unshift() adiciona no início; splice() remove, substitui ou insere no array original.

Métodos que retornam valores

map() transforma itens; filter() seleciona; find() retorna o primeiro correspondente; findIndex() retorna índice; reduce() acumula; some() verifica se algum atende; every() verifica se todos atendem.

Consultar e percorrer

forEach() executa uma função por item; includes() verifica presença; slice() retorna parte sem alterar o original. Desestruturação extrai valores; spread (...) copia ou combina; optional chaining (?.) evita erro ao acessar propriedade de valor nulo ou indefinido.

Strings e números

trim() remove espaços das extremidades; split() divide string; join() une itens; Number() converte para número e toFixed() formata casas decimais como texto.

Métodos de array
const tarefas = [
    { titulo: "Estudar", concluida: true },
    { titulo: "Praticar", concluida: false }
];

const titulos = tarefas.map(t => t.titulo);
const pendentes = tarefas.filter(t => !t.concluida);
const primeira = tarefas.find(t => t.concluida);

const numeros = [1, 2, 3, 4];

const parte = numeros.slice(1, 3); // [2, 3], original intacto

numeros.splice(1, 1); // altera o original
05
NAVEGADOR

DOM, eventos, armazenamento e APIs

O DOM representa o HTML como objetos que JavaScript pode consultar e alterar. Eventos permitem responder a cliques, teclado, entrada de dados e envio de formulários.

DOM e eventos

querySelector() seleciona o primeiro elemento; querySelectorAll() retorna uma lista; getElementById() busca por ID. textContent altera texto; innerHTML interpreta HTML e não deve receber conteúdo não confiável. classList oferece add(), remove(), toggle() e contains().

Criar e validar

createElement() cria; append() insere; remove() remove. addEventListener() registra eventos. O objeto event fornece detalhes; preventDefault() impede a ação padrão; a propagação pode ser controlada quando necessário.

JSON e localStorage

JSON.stringify() converte valores compatíveis em texto JSON; JSON.parse() lê esse texto. localStorage guarda strings entre sessões; converta objetos com JSON e não armazene informações sensíveis sem uma arquitetura apropriada.

Assíncrono e módulos

Promises representam operações futuras; async/await facilita código assíncrono. fetch() faz requisições HTTP: verifique response.ok. import/export dividem o código. Use try/catch/finally para erros e ferramentas do navegador para depuração.

Formulário e DOM
const formulario = document.querySelector("#formulario");
const campo = document.querySelector("#nome");
const saida = document.querySelector("#saida");

formulario.addEventListener("submit", evento => {
    evento.preventDefault();

    const nome = campo.value.trim();

    if (!nome) {
        saida.textContent = "Digite seu nome.";
        return;
    }

    saida.textContent = `Olá, ${nome}!`;
});
Fetch e async/await
async function carregarDados() {
    try {
        const resposta = await fetch("https://api.exemplo.com/dados");

        if (!resposta.ok) {
            throw new Error("Falha na requisição");
        }

        const dados = await resposta.json();

        console.log(dados);
    } catch (erro) {
        console.error("Não foi possível carregar:", erro);
    }
}

QUALIDADE

Boas práticas e erros comuns

Boas práticas

Use nomes claros, funções pequenas, const por padrão, validação de entradas, tratamento de falhas assíncronas e módulos para organizar projetos. Prefira textContent para inserir texto simples.

Erros comuns

Confundir = com comparação; esperar que map() altere o array original; usar innerHTML com dados não confiáveis; esquecer imports; acessar elementos antes do HTML existir; ignorar falhas de rede.

HTML + CSS + JavaScript
<!-- HTML -->
<button id="alternar" aria-pressed="false">Ativar destaque</button>
<p id="texto">Este texto terá destaque.</p>

/* CSS */
.destaque {
    color: #55b7ff;
    font-weight: 700;
}

// JavaScript
const botao = document.querySelector("#alternar");
const texto = document.querySelector("#texto");

botao.addEventListener("click", () => {
    const ativo = texto.classList.toggle("destaque");

    botao.setAttribute("aria-pressed", String(ativo));
});

HTML fornece os elementos, CSS define a classe visual e JavaScript alterna a classe em resposta ao clique.
