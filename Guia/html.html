01

PRIMEIROS PASSOS

O que é HTML?

HTML significa HyperText Markup Language (Linguagem de Marcação de Hipertexto). Ele descreve o conteúdo e a estrutura de uma página usando elementos. Pense numa página como um documento: HTML organiza títulos, parágrafos, imagens, links e outras partes para que navegadores e tecnologias assistivas entendam suas relações.

Estrutura, aparência e comportamento

HTML dá estrutura e significado. CSS define a apresentação visual, como cores e espaçamento. JavaScript pode responder a ações e atualizar a página. No começo, concentre-se em HTML: uma página útil não precisa de efeitos para ser bem estruturada.

Elementos e tags

Uma tag é uma instrução entre sinais de menor e maior, como <p>. Um elemento geralmente reúne tag de abertura, conteúdo e tag de fechamento: <p>Olá!</p>. Algumas tags, como <img> e <meta>, não envolvem conteúdo e não têm fechamento.

Seu primeiro documento

<!doctype html>
<html lang="pt-BR">
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width, initial-scale=1">
        <title>Minha primeira página</title>
    </head>

    <body>
        <h1>Olá, mundo!</h1>
        <p>Esta é minha primeira página.</p>
    </body>
</html>

Entenda cada parte

  • <!doctype html> informa ao navegador que o documento usa HTML moderno.
  • <html lang="pt-BR"> envolve a página; o idioma ajuda leitores de tela e ferramentas de tradução.
  • <head> guarda informações sobre o documento, que em geral não aparecem no conteúdo da página.
  • charset permite exibir corretamente caracteres como acentos; viewport ajuda a página a caber em telas móveis.
  • <title> define o título da aba. <body> contém o conteúdo apresentado à pessoa.

Pratique · sua primeira página

  1. Crie um arquivo chamado index.html em um editor de texto.
  2. Digite a estrutura acima, trocando o título e o parágrafo por informações suas.
  3. Salve e abra o arquivo no navegador. Depois mude uma frase, salve novamente e atualize a página.

Observe: o texto de <title> aparece na aba; o texto do <body> aparece na página.

Confira antes de seguir

  • Sei explicar a diferença entre HTML e CSS?
  • Sei localizar o conteúdo visível dentro de <body>?
  • Minha página tem idioma, codificação e título?
02

ESCREVER CONTEÚDO

Títulos, parágrafos e ênfase

Use elementos de texto pelo papel que o conteúdo desempenha. A aparência pode ser ajustada depois com CSS; escolher o elemento pelo significado mantém a página compreensível mesmo quando muda de tela ou é lida por tecnologia assistiva.

Uma hierarquia de títulos

<h1> representa o título principal da página ou do assunto. <h2> apresenta uma seção; <h3>, um tópico dentro dela. Siga a hierarquia do conteúdo, como num sumário. Não escolha um nível apenas porque seu tamanho parece bonito.

Parágrafos e ênfase

<p> marca um parágrafo. <strong> indica importância; <em> dá ênfase na leitura. Eles não são apenas estilos de negrito e itálico. Use <br> somente quando uma quebra de linha fizer parte do conteúdo, como num endereço ou poema.

Uma hierarquia clara

<main>
    <h1>Meu caderno de jardinagem</h1>
    <p>Anotações para cuidar das plantas em casa.</p>

    <section>
        <h2>Começando uma horta</h2>
        <p>Escolha um local que receba luz suficiente.</p>

        <h3>Escolha dos vasos</h3>
        <p>O tamanho depende das raízes de cada planta.</p>
    </section>
</main>
Comentário no código: use <!-- assim --> para deixar uma observação que não aparece na página. Comentários não substituem uma estrutura clara e podem ser vistos por qualquer pessoa que inspecione o arquivo.

Pratique · uma página sobre um interesse

  1. Escreva um título principal, uma introdução e duas seções.
  2. Dê a cada seção um <h2> e escreva pelo menos dois parágrafos.
  3. Adicione um subtópico com <h3>. Verifique se a ordem dos títulos parece um sumário lógico.

Erros comuns

  • Usar vários <h1> como forma de deixar texto grande. Use CSS para aparência e títulos para hierarquia.
  • Usar vários <br> para criar espaço. Parágrafos e CSS resolvem estrutura e espaçamento, respectivamente.
  • Pular de <h2> para <h5> por causa do tamanho padrão do navegador.

Revisão rápida

O título descreve o assunto? Cada seção tem um título que a identifica? Leia só os títulos: a sequência ainda faz sentido?

03

CONECTAR E ILUSTRAR

Links e imagens

Links levam a outro lugar; imagens acrescentam conteúdo visual. Em ambos os casos, atributos fornecem informações importantes. Um atributo aparece na tag de abertura e costuma ter o formato nome="valor".

Links que explicam o destino

<a> cria um link e href informa o destino. O texto clicável deve dizer para onde leva: “Consulte o catálogo de livros” é mais útil que “clique aqui”. Um caminho como contato.html aponta para um arquivo relativo; uma URL completa aponta para outro site.

Imagens com alternativa

<img> insere uma imagem; src informa onde ela está e alt oferece uma alternativa textual. Descreva a informação relevante, não cada detalhe visual. Se a imagem for puramente decorativa e não acrescentar conteúdo, use alt="".

Exemplo comentado: links e imagens 

<!-- Link para uma página do mesmo site -->
<a href="contato.html">Entre em contato</a>

<!-- Link externo; abrir na mesma aba costuma ser mais previsível -->
<a href="https://developer.mozilla.org/pt-BR/docs/Web/HTML">
    Leia a documentação de HTML
</a>

<!-- Alt descreve a informação que a imagem transmite -->
<img
    src="horta.jpg"
    alt="Vasos com ervas numa varanda ensolarada"
    width="640"
    height="420"
>

Sobre dimensões: largura e altura ajudam o navegador a reservar espaço antes de a imagem carregar. Informe proporções compatíveis com o arquivo para evitar distorções.

Pratique · mini página de recomendações

  1. Crie dois links: um para uma página do seu site e outro para uma fonte externa confiável.
  2. Escolha uma imagem disponível no seu projeto e escreva um alt que transmita seu propósito.
  3. Peça a alguém para ler apenas o texto dos links e a descrição da imagem. A pessoa entende o conteúdo?

Erros comuns

  • Esquecer href: sem destino, o link não leva a lugar algum.
  • Usar “imagem” como texto alternativo. Descreva a informação útil; não repita o que a pessoa já sabe.
  • Escrever “clique aqui” sem contexto ou deixar o alt ausente.

Revisão rápida

  • Consigo diferenciar o texto do link de seu destino?
  • As imagens informativas têm uma alternativa adequada?
  • Links continuam compreensíveis fora do parágrafo em que aparecem?
04

DAR SIGNIFICADO

Listas e estrutura semântica

HTML semântico usa elementos que comunicam o papel de cada parte. Isso ajuda pessoas a navegar, ferramentas assistivas a interpretar e quem desenvolve a entender o código. Primeiro pergunte “que tipo de conteúdo é este?”; depois escolha o elemento.

Listas

<ul> agrupa itens cuja ordem não importa; <ol> indica sequência ou classificação; cada item fica em <li>. Não use listas apenas para obter recuo ou marcadores: o grupo precisa fazer sentido como lista.

Partes da página

<header> é uma introdução ou cabeçalho; <nav> reúne navegação; <main> contém o assunto principal; <section> agrupa um tema; <article> é conteúdo que faz sentido por si; <aside> é complementar; <footer> traz informações finais.

Exemplo comentado: página com significado 

<header>
    <h1>Caderno de trilhas</h1>

    <nav aria-label="Navegação principal">
        <a href="#trilha-do-dia">Trilha do dia</a>
        <a href="#preparacao">Preparação</a>
    </nav>
</header>

<main>
    <section id="trilha-do-dia">
        <h2>Trilha do dia</h2>

        <article>
            <h3>Caminho da cachoeira</h3>
            <p>Percurso curto com trechos sombreados.</p>
        </article>
    </section>

    <section id="preparacao">
        <h2>O que levar</h2>

        <ul>
            <li>Água</li>
            <li>Protetor solar</li>
        </ul>
    </section>
</main>

<footer>
    <p>Atualizado em 2026.</p>
</footer>

div é um contêiner genérico, sem significado especial. Use quando nenhum elemento semântico servir. Evite escolher elementos apenas pela forma como o navegador os apresenta por padrão.

Pratique · organize uma página

  1. Esboce no papel cabeçalho, navegação, conteúdo principal e rodapé.
  2. Converta o esboço em elementos semânticos, com um <main> e títulos coerentes.
  3. Faça uma lista de passos ou materiais com <ol> ou <ul>, conforme o sentido.

Erros comuns

  • Usar <section> como sinônimo de qualquer caixa visual. Em geral, uma seção deve ter um tema e título.
  • Colocar mais de um conteúdo principal independente em <main>.
  • Usar uma tabela para posicionar elementos. Tabelas são para dados organizados em linhas e colunas.

Revisão rápida

Se eu remover o CSS, a ordem e o propósito do conteúdo continuam claros? Cada parte usa o elemento que descreve melhor sua função?

05

RECEBER INFORMAÇÕES

Formulários acessíveis

Formulários permitem que uma pessoa envie dados ou escolha opções. Cada controle precisa de uma instrução visível e associada. Um campo com placeholder sozinho não tem um rótulo adequado: a dica desaparece quando a pessoa começa a digitar.

Rótulo, identificador e nome

<label> explica o campo. Seu for deve corresponder ao id único do controle. O atributo name identifica o dado quando um formulário real é enviado. type escolhe o controle, por exemplo email ou text.

Validação básica

required marca um campo obrigatório; autocomplete pode ajudar o navegador a preencher dados conhecidos. Validação no navegador melhora a experiência, mas um site que recebe dados também precisa validá-los no servidor.

Exemplo comentado: campos relacionados 

<form action="/contato" method="post">
    <!-- for e id associam o rótulo ao campo -->
    <label for="nome">Seu nome</label>
    <input
        id="nome"
        name="nome"
        type="text"
        autocomplete="name"
        required
    >

    <label for="email">E-mail</label>
    <input
        id="email"
        name="email"
        type="email"
        autocomplete="email"
        required
    >

    <label for="mensagem">Mensagem</label>
    <textarea id="mensagem" name="mensagem" rows="4"></textarea>

    <button type="submit">Enviar mensagem</button>
</form>

Este exemplo mostra a estrutura HTML. O envio depende de um endereço de servidor que receba e processe os dados; sem esse serviço, o formulário não envia uma mensagem de verdade.

Pratique · formulário de inscrição

  1. Adicione campos para nome, e-mail e uma mensagem.
  2. Para cada controle, confira se for e id coincidem e se o name está definido.
  3. Navegue usando a tecla Tab e confira se o foco passa por rótulos, campos e botão em ordem lógica.

Erros comuns

  • Usar texto de exemplo como único rótulo do campo.
  • Repetir valores de id ou esquecer o name.
  • Usar <button> sem definir o tipo em contextos com formulário. type="submit" envia; type="button" não envia por padrão.

Revisão rápida

Um leitor de tela consegue identificar o propósito de cada campo? O foco do teclado chega a todos os controles? Está claro o que acontece ao enviar?

06

JUNTAR AS PEÇAS

Projeto final: uma página sobre você

Agora use os conceitos para criar uma página pequena, mas completa. Faça primeiro o conteúdo funcionar sem CSS. O objetivo é praticar estrutura, não decorar todas as tags de uma vez.

Requisitos

  • Estrutura completa com idioma, título e metadados.
  • Um cabeçalho, navegação, conteúdo principal e rodapé.
  • Um título principal e seções com títulos em ordem.
  • Uma lista, pelo menos um link e uma imagem com alternativa.
  • Um formulário de contato com rótulos associados.

Checklist de revisão

  • Abri e atualizei o arquivo no navegador?
  • Os elementos estão fechados e aninhados corretamente?
  • Os links têm destinos e nomes que fazem sentido?
  • Consigo navegar com Tab e entender os campos?
  • O idioma está correto e a hierarquia faz sentido sem estilos?

O que você já sabe fazer

Você aprendeu a montar um documento HTML, organizar texto, conectar páginas, descrever imagens, estruturar conteúdo semanticamente e criar campos de formulário mais acessíveis. Continue praticando com páginas pequenas; consulte uma referência quando surgir uma dúvida específica.
