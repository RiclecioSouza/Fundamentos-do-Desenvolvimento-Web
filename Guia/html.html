01
CONCEITO

Introdução ao HTML

HTML (HyperText Markup Language) é uma linguagem de marcação que descreve a estrutura e o significado do conteúdo de uma página. Organiza títulos, textos, links, imagens, listas, tabelas e formulários; não é uma linguagem de programação.

HTML, CSS e JavaScript

HTML estrutura o conteúdo; CSS controla sua apresentação; JavaScript acrescenta lógica e interação. As três tecnologias trabalham em conjunto.

Estrutura do documento

<!DOCTYPE html> identifica HTML moderno; html envolve o documento; head contém metadados; meta define informações como UTF-8 e viewport; title define o título da aba; body contém o conteúdo visível.

Estrutura mínima 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Minha página</title>
</head>
<body>
    <h1>Olá, mundo!</h1>
    <p>Meu primeiro documento HTML.</p>
</body>
</html>
02
ELEMENTOS

Tags por finalidade

As tags identificam elementos do documento. Escolha cada elemento pelo significado do conteúdo, não apenas pela aparência.

Textos

h1 a h6 são títulos hierárquicos; p cria parágrafos; strong indica importância; em dá ênfase; small representa observações secundárias; span agrupa texto em linha; br quebra a linha quando necessário ao conteúdo.

Estrutura semântica

header é cabeçalho; nav agrupa navegação; main contém o conteúdo principal; section agrupa um tema; article é conteúdo independente; aside é complementar; footer é rodapé. div é um contêiner genérico.

Links e mídia

a cria links; img exibe imagens; audio e video incorporam mídia; iframe incorpora outra página. Imagens informativas devem ter texto alternativo em alt.

Listas

ul cria listas sem ordem; ol cria listas ordenadas; li representa cada item. Escolha de acordo com o sentido da informação.

Tabelas

table cria tabela; thead agrupa cabeçalhos; tbody agrupa dados; tr é linha; th é célula de cabeçalho; td é célula de dados. Use tabelas para dados tabulares.

Formulários

form agrupa campos; label identifica campo; input recebe valores; textarea recebe texto longo; select e option criam opções; button cria botão.

Complementares

figure agrupa mídia; figcaption adiciona legenda; time marca data/hora; details cria conteúdo expansível e summary seu rótulo.

03
ATRIBUTOS

Atributos HTML

Atributos fornecem informações ou configuram o comportamento de um elemento e geralmente aparecem na tag de abertura como nome="valor".

Identificação e links

id identifica um elemento de forma única; class agrupa elementos. href define o destino de um link e target="_blank" abre outra aba; considere rel="noopener".

Mídia e formulários

src define a origem da mídia e alt oferece alternativa textual. type define o tipo do campo; name é o nome enviado; value é o valor; placeholder é uma dica e não substitui o rótulo; for associa label e campo.

Estados e dimensões

required exige preenchimento; disabled desativa um controle; checked marca checkbox/radio. width e height definem dimensões em elementos compatíveis; title fornece informação adicional.

data-* e globais

data-categoria="livro" guarda dado personalizado para JavaScript. Atributos booleanos são ativados pela presença. Atributos globais incluem id, class, lang, hidden e tabindex.

Exemplo de atributos 
<label for="email">E-mail</label>
<input id="email" name="email" type="email"
       placeholder="voce@exemplo.com" required>

<a href="https://exemplo.com" target="_blank"
   rel="noopener">Abrir exemplo</a>

<img src="foto.jpg" alt="Pessoa lendo um livro"
     width="320" height="200">
04
ACESSIBILIDADE

Semântica, boas práticas e erros comuns

Elementos semânticos comunicam o papel do conteúdo a navegadores, tecnologias assistivas e pessoas que leem o código. Use div quando não houver elemento mais apropriado.

Acessibilidade

Mantenha hierarquia lógica de títulos; use alt útil em imagens informativas e alt="" em imagens decorativas; associe label aos campos; use links para navegar e botões para ações.

Evite estes erros

Não repita id; não use br para espaçamento visual; não esqueça o texto alternativo; não use tabelas para layout; não pule níveis de título sem motivo nem transforme uma div em botão sem teclado e semântica adequados.

Exemplo semântico 
<header>
    <h1>Clube de leitura</h1>
</header>

<nav aria-label="Principal">
    <a href="#livros">Livros</a>
</nav>

<main>
    <section id="livros">
        <h2>Livro em destaque</h2>

        <article>
            <h3>O pequeno príncipe</h3>
            <p>Uma leitura para refletir sobre relações.</p>
        </article>
    </section>
</main>

<footer>
    <p>Conteúdo educativo.</p>
</footer>
SÍNTESE FINAL

O que levar deste guia

HTML descreve a estrutura e o significado do conteúdo. Elementos semânticos, títulos bem organizados e alternativas acessíveis tornam os documentos mais claros e fáceis de manter.
