# 📚 Guias Educativos de Front-end
Repositório dedicado ao estudo e à consulta de conteúdos do desenvolvimento Front-end. O projeto reúne guias educativos sobre **HTML, CSS e JavaScript**, organizados para facilitar o aprendizado e a compreensão dos principais conceitos dessas tecnologias.

## 📂 Estrutura do projeto
O projeto está dividido em três guias principais:

### 🌐 HTML — `html.html`
Guia sobre a estruturação de páginas web, abordando os seguintes conteúdos:

* Fundamentos de HTML
* Tags
* Atributos
* Semântica
* Acessibilidade

### 🎨 CSS — `css.html`
Guia sobre estilização e apresentação de páginas web, incluindo:

* Seletores
* Pseudoclasses
* Propriedades
* Layouts
* Responsividade
* Transformações
* Animações

### ⚡ JavaScript — `javascript.html`
Guia sobre os fundamentos da linguagem JavaScript e seus principais recursos:

* Fundamentos da linguagem
* Funções
* Arrays
* DOM
* Eventos
* Armazenamento
* Módulos
* APIs

## 🎯 Objetivo
Criar materiais de consulta que facilitem o aprendizado de Front-end, reunindo conceitos, explicações e exemplos práticos em um só lugar.

## 🛠️ Tecnologias utilizadas
* **HTML5:** estruturação do conteúdo.
* **CSS3:** estilização e responsividade.
* **JavaScript:** recursos de programação e interatividade.
