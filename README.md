# Fundamentos-do-Desenvolvimento-Web
Uma página informativa que apresenta os principais
conceitos, linguagens e tecnologias utilizados no desenvolvimento de
sites e aplicações web.

## 📌 Sobre o projeto
O Guia de Desenvolvimento Web foi criado para reunir em uma única
página, explicações introdutórias sobre como diferentes partes de uma
aplicação web se relacionam. O conteúdo utiliza textos objetivos,
cartões informativos e diagramas visuais para facilitar a compreensão
dos conceitos.

## 📚 Conteúdo abordado
Introdução ao Desenvolvimento Web: o que é desenvolvimento web,
para que serve e como funciona.

Como as partes se relacionam: visão geral do fluxo entre
Front-end, Back-end e banco de dados.

Front-end: funções do HTML, CSS e JavaScript.

Back-end: explicação sobre processamento no servidor e
apresentação de linguagens como JavaScript com Node.js, Python, PHP,
Java, C# e Ruby.

Banco de Dados: introdução aos bancos relacionais e não
relacionais (NoSQL).

Desenvolvimento Web moderno: conceitos de responsividade, APIs,
frameworks e bibliotecas, segurança, performance e acessibilidade.

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3

## 🎯 Objetivo
O objetivo do projeto é apresentar fundamentos do Desenvolvimento Web de
forma acessível e visual, servindo também como prática de estruturação
HTML e estilização com CSS.

Projeto educativo desenvolvido para estudo e prática de desenvolvimento
Front-end.
