Introdução ao Desenvolvimento Web

⌘

O que é Desenvolvimento Web?

Desenvolvimento Web é o processo de criação e manutenção de sites e aplicações que funcionam por meio da Internet ou de uma rede.

Ele envolve diferentes áreas responsáveis pela aparência, interação, processamento de informações e armazenamento dos dados de uma aplicação.

01

Para que serve?

Permite criar desde páginas simples até sistemas completos, como lojas, plataformas educacionais, redes de conteúdo e aplicações empresariais.

02

Como funciona?

De forma simplificada, o navegador apresenta a interface, o servidor processa as solicitações e o banco de dados armazena as informações.

INTERFACE

Front-end

Front-end é a parte do desenvolvimento responsável pela interface que aparece no navegador. É onde são construídos os elementos que o usuário visualiza e utiliza.

</>
ESTRUTURA

HTML

Define a estrutura e a organização do conteúdo de uma página, como títulos, textos, imagens, listas e seções.

FUNÇÃO Estruturar o conteúdo
#
APARÊNCIA

CSS

Controla a aparência da página. Define cores, fontes, espaçamentos, tamanhos, posicionamento e layout.

FUNÇÃO Estilizar e organizar
JS
INTERAÇÃO

JavaScript

Adiciona lógica, interatividade e comportamento dinâmico às páginas e aplicações web.

FUNÇÃO Criar comportamentos
HTML + CSS + JavaScript

Essas três tecnologias formam uma base fundamental do Front-end: o HTML organiza, o CSS apresenta e o JavaScript adiciona comportamento e interação.

PROCESSAMENTO

Back-end

O Back-end funciona principalmente nos servidores. Ele recebe solicitações, aplica regras de negócio, processa informações e conversa com bancos de dados e outros serviços.

{ }

O que acontece por trás da interface?

Quando uma aplicação precisa realizar uma operação, como autenticar um usuário ou consultar informações, o Back-end pode receber essa solicitação e determinar o que deve acontecer.

Existem diversas linguagens e ambientes capazes de desempenhar esse papel. A escolha depende do projeto, da equipe e das necessidades da aplicação.

01

JavaScript / Node.js

Permite utilizar JavaScript também no lado do servidor por meio do ambiente Node.js.

02

Python

Linguagem conhecida pela sintaxe relativamente simples e utilizada em diferentes tipos de sistemas.

03

PHP

Linguagem tradicionalmente muito presente no desenvolvimento de aplicações e sites dinâmicos.

04

Java

Utilizada em aplicações de diferentes escalas, incluindo sistemas corporativos e serviços web.

05

Linguagem utilizada no ecossistema .NET para desenvolver aplicações e serviços.

06

Ruby

Linguagem conhecida pela sintaxe expressiva e utilizada também no desenvolvimento de aplicações web.

ARMAZENAMENTO

Banco de Dados

Bancos de dados são utilizados para armazenar e organizar informações. Em uma aplicação web, eles permitem que dados importantes sejam mantidos e posteriormente consultados, alterados ou removidos.

▤
TIPO 01

Bancos Relacionais

Organizam os dados principalmente em tabelas formadas por linhas e colunas. As informações podem se relacionar entre diferentes tabelas.

✓ Estrutura organizada
✓ Relacionamento entre dados
◇
TIPO 02

Bancos Não Relacionais

Também chamados de NoSQL, utilizam modelos mais flexíveis para armazenar determinados tipos de informação.

✓ Estrutura mais flexível
✓ Diferentes modelos de armazenamento
i

Em termos simples: o banco de dados funciona como uma memória organizada da aplicação. Ele guarda as informações para que o sistema possa utilizá-las quando necessário.

ECOSSISTEMA

Desenvolvimento Web moderno

01

Responsividade

Capacidade de uma interface se adaptar a diferentes tamanhos de tela, como computadores, tablets e smartphones.

02

APIs

Interfaces que permitem que diferentes sistemas ou serviços troquem informações de maneira organizada.

03

Frameworks e bibliotecas

Conjuntos de ferramentas e recursos que ajudam a desenvolver aplicações de forma mais estruturada e produtiva.

04

Segurança

Envolve proteger aplicações, informações e usuários contra acessos indevidos e diferentes tipos de ameaças.

05

Performance

Busca fazer com que páginas e aplicações carreguem e respondam rapidamente, utilizando os recursos de maneira eficiente.

06

Acessibilidade

Procura garantir que pessoas com diferentes necessidades possam perceber, navegar e utilizar a aplicação.

07 · CONCLUSÃO

Um ecossistema de tecnologias

O Desenvolvimento Web reúne diferentes tecnologias trabalhando em conjunto. HTML, CSS e JavaScript formam uma base importante para o Front-end, enquanto diferentes linguagens podem ser utilizadas no Back-end.

Os bancos de dados armazenam as informações utilizadas pelas aplicações, enquanto conceitos como segurança, acessibilidade, performance e responsividade ajudam a construir experiências mais completas e confiáveis.
